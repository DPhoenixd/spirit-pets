# 灵兽游记 · 寻灯之旅

0.383 网页试玩版。用电脑上的 Edge、Chrome 或 Firefox 打开游戏。

- WASD 走路，向前移时按住 Shift 奔跑，C 滑铲，空格跳跃。奔跑时变向接跳可保留起跳速度。
- 左键攻击，右键瞄准，R 换弹，1 / 2 切武器。
- Q 主技能，E 副技能或互动，F 拾取，Tab 查看武器，Esc 暂停。
- 画面设置可调整镜头晃动。鼠标灵敏度和音量在设置中调整。

音频署名见 [AUDIO-CREDITS.md](AUDIO-CREDITS.md)。Three.js 许可见 [THREE-LICENSE.txt](THREE-LICENSE.txt)。

在主菜单打开「灵修树」→「出发数值与进度管理」→「备份与恢复」，可把灵露、天赋与已解锁武器带到另一浏览器或离线版本。结算可单独导出。

每位伙伴有独立灵修树，并共享通用天赋。主菜单可预览开局数值、重置单棵树或备份局外进度。局外武器解锁和天赋均消耗灵露。

在竹林的补给点靠近货郎，按 F 打开武器、海克斯锦囊和补给货架。购买锦囊后，本趟冒险立即获得对应海克斯。

按 V 切换第一人称和右肩视角。过肩角色的手爪、袖口、轮廓和衣摆已更新。

糯米的 E 技能「穿花影」在过肩视角下交替下劈与回挑，围巾、衣摆和尾巴随每一斩摆动。

糯米的 Q 技能「掠影斩」用当前冷兵器出招。持枪时会临时拔出柳叶短剑，冲刺后切回枪械。

过肩视角下，糯米释放「穿花影」时会朝每个目标转身。鼠标可继续控制镜头。

三章近景岩壁更新了石纹和风化层次，远处的细纹逐渐淡出。

牌楼与廊桥的屋瓦增加了釉色变化、瓦沟水痕和轻微磨损。

过肩视角下，角色在坡面落地时会为两只脚爪分别找落点。

修正起点渡口石台及连廊岔路的地面碰撞。滑铲抵达悬空边缘时会短暂刹停。

第一人称连发时，枪械会在前一发的回弹上接续下一发动作。

妖灵的受击动作会随命中方向和高度变化，连续命中后会逐步收稳。

妖灵的木甲、陶面和石壳采用不同的凹凸与反光，近看可辨认木纹和磨痕。

群怪战斗减少了角色姿势和特效可见范围的重复计算。

在补给点靠近山路铁铺，按 F 查看当前武器的熔炼成功率、花费和可能追加的质变。确认时扣款，取消可返回报价。
